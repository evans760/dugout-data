Playing-time spread is reported here because it's a question organizations ask early: does this tool only flatter the star players? It doesn't — every rostered player with enough plate appearances gets tier-and-distance framing (never a rank) in their own report, and every player below the reliability floor still gets an honest, encouraging counting-stats report instead of being skipped.

How It Stays Safe to Hand to a Parent

Every individual report runs through an automated check before it's written to disk: the rendered HTML is scanned against the full roster name list, and the build fails outright if any teammate's name appears in a single-player report. No hand-review step to forget, no manual redaction. Team-average comparisons are also audited — if a roster's OPS is unusually high, the tool switches from a team-average bar to a distribution view so no kid's honest season reads as a letdown just because of who else is on the team.
